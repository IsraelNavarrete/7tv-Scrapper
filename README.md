# 7tv-Scrapper
Programa de consola utilizado para descargar emotes de la página de 7tv.app

Al ejecutarlo se abre una consola de comandos, sigue las instrucciones del programa.

Es una demo muy sencillita pero también lo podeis usar si acabais de empezar en rust (como yo) y quereis ver un poco lo que se puede hacer y como funciona el lenguaje, aunque como soy nuevo seguramente tenga 10000 errores
